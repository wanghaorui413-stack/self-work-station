# 0003 工作台做成 Electron 桌面程序，不再依赖浏览器打开

- 状态：已接受（取代 ADR 0001 中“本地服务器单独常驻 + 工作台作为 Edge 应用常驻”的部分）
- 日期：2026-11-02

## 背景

ADR 0001 让工作台以“本地 Node 服务器 + Edge 安装为应用”的方式常驻。实际用下来有两个问题：

- 用户明确不想依赖浏览器打开，希望它是一个真正的桌面程序。
- 服务器和页面是两个独立的东西：服务器没开、或者代码更新后没重启，页面就显示“未连接本地服务器”，用户得自己去结束进程、再重新拉起来。

## 决定

- 用 **Electron** 把现有页面包成桌面程序：独立窗口、自己的任务栏图标、托盘图标；关窗口时缩到托盘，提醒照常弹出；开机自启由程序自己管理。
- 原 `scripts/serve.mjs` 里的数据读写逻辑在 Electron 主进程里直接运行，不再需要单独的后台服务器进程。
- 页面代码继续用原生 HTML/CSS/JS，不引入前端框架（沿用之前的决定）。
- 数据位置、Claude 定时任务写 `data/items.json` 的方式、数据只留在本机，这些都不变（ADR 0001、0002 的其余部分继续有效）。

## 考虑过的其他方案

- **继续用 Edge 的“安装为应用”**：零成本，但本质上还是浏览器，服务器和页面分离的问题也还在。
- **Tauri**：安装包小很多，但要装 Rust 工具链，现有 Node 服务器要么改写成 Rust，要么作为额外进程挂进去，工作量和维护成本都明显更高。

## 后果

- 项目第一次需要 `npm install`，Electron 约 100MB，“零依赖”的定位放弃。
- GitHub Pages 上的 `?demo=1` 演示照常可用：页面本身仍是静态文件。
- 开机自启改由程序设置，原来的 `scripts/windows/` 自启脚本将被替换。
