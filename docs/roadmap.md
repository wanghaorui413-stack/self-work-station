# Roadmap

## V1：每日计划原型

- 自动生成每日时间表
- 任务计时器
- 5 分钟启动
- 本地保存
- 每日复盘

## V2：数据闭环版

- 近 7 天完成率
- 薄弱模块识别
- 连续均衡日
- 模块完成分布
- 策略说明和系统提醒

## V3：招聘事项工作台（当前）

- Claude 定时任务每天两次读 Gmail（由 163 转发而来），提取面试、测评、AI 面试
- 固定日程 / 截止任务两类建模，占用时段含准备、缓冲和交通
- 截止任务自动排进空档，均衡任务避让；被挤占的模块不计入跳过
- Windows 系统通知：前一天 20:00、提前 1 小时、截止前 24 小时
- 本地服务器读写 data/items.json，开机自启 + Edge 应用常驻

## V4：个人工作台

从雅思计划器改成通用的个人工作台（词汇见 GLOSSARY，存储见 ADR 0002）。按以下顺序分段交付，每段完成后都能直接用上：

1. ✅ **数据底座 + 投入方向设置**：数据迁到本机 `data/`；可以增删改投入方向（最低保障时间、权重、生效日、每天几段）；原有 6 个方向保留，历史统计不中断；`app.js` 拆成多个原生 ES module。
2. ✅ **桌面外壳**（ADR 0003）：Electron 桌面程序（独立窗口、托盘常驻、开机自启，不再需要单独的后台服务器）；左侧导航 + 多视图（今天、日历、待办、投入方向、招聘、复盘、设置）；今天页改成按时间比例的竖向时间轴，计时器固定在右侧，时段默认收起、点开看详情；整体改成桌面软件的紧凑密度，配色保留。功能不变，只换形态。
3. **待办 + 手动建事项**：手动建固定日程、截止任务、待办；待办可标记“今天做”，出现在今天页。
4. **日历周视图**（月视图之后再做）。
5. **固定日程每周重复**。
6. **招聘页**：按公司查看进度。
7. **文档**：README 和作品集材料改为按个人工作台的定位来讲。

暂缓：拖拽调整时段顺序和时长、导出 / 导入备份（复制 `data/` 文件夹就能备份）、周报导出为 Markdown。

## V5：智能辅助

- 根据历史完成情况自动建议次日配比
- 根据弱项自动生成更小的启动目标
- 复盘内容自动总结
- 可选云同步或后端账户系统
