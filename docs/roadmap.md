# Roadmap

## V1：每日计划原型

- 自动生成每日时间表
- 任务计时器
- 5 分钟启动
- 本地保存
- 每日复盘

## V2：数据闭环版

- 近 7 天完成率
- 薄弱模块识别
- 连续均衡日
- 模块完成分布
- 策略说明和系统提醒

## V3：招聘事项工作台（当前）

- Claude 定时任务每天两次读 Gmail（由 163 转发而来），提取面试、测评、AI 面试
- 固定日程 / 截止任务两类建模，占用时段含准备、缓冲和交通
- 截止任务自动排进空档，均衡任务避让；被挤占的模块不计入跳过
- Windows 系统通知：前一天 20:00、提前 1 小时、截止前 24 小时
- 本地服务器读写 data/items.json，开机自启 + Edge 应用常驻

## V4：可配置与导出

- 自定义任务类别
- 自定义权重和最低保障时间
- 导出 / 导入 JSON 备份
- 周报导出为 Markdown

## V5：智能辅助

- 根据历史完成情况自动建议次日配比
- 根据弱项自动生成更小的启动目标
- 复盘内容自动总结
- 可选云同步或后端账户系统
